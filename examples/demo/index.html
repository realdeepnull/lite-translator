Live input

Live translation while typing — like chat messages or speech-to-text. Sentences are segmented; completed sentences are cached and only the growing tail is re-translated. Outdated results are discarded automatically.

Batch translation

Translate several longer texts at once. The toggle enables processing all texts; when turned off, only the first text is translated.

i18n style (t / translateAll)

Register UI strings spread across several "components" via t(key, text); clicking "Translate all" performs exactly one translateBatch call for all registered strings. Identical values are deduplicated before inference (e.g. "Abbrechen"). Reactive via store.subscribe().
