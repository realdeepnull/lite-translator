Batch-Übersetzung

Mehrere längere Fließtexte auf einmal übersetzen. Der Toggle aktiviert die Abarbeitung aller Texte; ausgeschaltet wird nur der erste Text übersetzt.

Voraussetzung Zuerst npm run build im Repo ausführen. Diese Seite lädt die lokalen dist-Bundles der Workspace-Pakete direkt (ohne separaten Bundler). Die erste Übersetzung lädt das quantisierte Modell vom Hugging Face Hub.
